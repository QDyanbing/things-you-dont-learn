# Glossary

This glossary defines the terms used across the upload SDK, browser demo, and
local API server docs. Keep new terms here when a concept is shared by more than
one guide.

## SDK Terms

- File identity: Metadata-derived id used by `FileCoordinator` for one selected
  file.
- Chunk index: Zero-based SDK index for one prepared file chunk.
- Chunk identity: Metadata-derived id built from file identity, chunk index, and
  byte range.
